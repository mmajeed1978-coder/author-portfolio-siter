# Author Portfolio — المرحلة الأولى

واجهة أولية لموقع شخصي لأكاديمي وروائي وناقد سينمائي، مبنية بـ Next.js وCSS.

## تشغيل المشروع

```bash
npm install
npm run dev
```
ثم افتح http://localhost:3000

## ملاحظات المرحلة
- التصميم مستوحى مباشرة من الـmockup المرفق.
- الاسم والكتب والصور الحالية بيانات تجريبية قابلة للاستبدال.
- المرحلة التالية: صفحات التفاصيل، الحسابات، مكتبة المستخدم، نظام السلة والدفع، وحماية الكتب الرقمية.
